4. 고전 게임 룩 (공통 효과)

파로디우스·KOF·메가맨·배틀시티 레퍼런스. 아래 4종을 전 컴포넌트에 공통 적용. 핵심은 border-radius:0 + blur 0 그림자.

① 이중 픽셀 테두리
각진 모서리 + 안쪽 한 겹 + 픽셀 베벨
border-radius:0 필수
② 픽셀 베벨 그림자
blur 0 · 딱딱한 계단식 그림자
box-shadow: 4px 4px 0 0 #000
③ 스캔라인 오버레이
CRT 가로줄 · 게임 영역 ::after
repeating-linear-gradient + multiply
④ 픽셀 프레임
게임 영역을 감싸는 액자형 테두리
다중 inset box-shadow
