# Screen Specification — 나의 속도

## 1.1 Title Screen / 시작 화면

### 1. 화면 목적

게임 시작 전 플레이어가 처음 마주하는 화면.
게임의 분위기와 핵심 메시지를 전달하고, 플레이어가 부담 없이 게임에 진입하도록 한다.

### 2. 화면 구성 요소

- 게임 타이틀
- 시작 안내 문구
- 시작 버튼
- 배경 주행 연출
- 중앙 게임 영역
- 양옆 배너 영역

### 3. 플레이어 행동

- 시작 버튼을 누른다.
- 버튼 입력 시 게임이 시작된다.
- 동시에 오디오 언락이 실행된다.

### 4. 사용 문구

메인 문구:
달려도, 걸어도 괜찮아요.
당신만의 속도를 찾아볼게요.

버튼:
내 속도 찾아보기

### 5. 비주얼 / 연출

- 배경 플레이 화면이 천천히 움직인다.
- 캐릭터 또는 길이 은근하게 주행 중인 듯 보인다.
- 전체 분위기는 차분하고 저채도 픽셀아트 톤을 유지한다.
- 배너는 아직 과하게 시끄럽지 않다.

### 6. 사운드

- 시작 버튼 클릭 후 BGM과 효과음을 활성화한다.

### 7. 진입 조건

- 사용자가 게임 URL에 처음 접속했을 때 표시된다.

### 8. 전환 조건

- 시작 버튼 클릭 시 Tutorial Screen / 조작 안내 화면으로 이동한다.

### 9. 주의사항

- 첫 화면에서 게임 규칙을 모두 설명하지 않는다.
- “도전하기”, “기록 세우기”, “빠르게 시작하기”처럼 경쟁이나 속도 압박을 주는 문구는 사용하지 않는다.
- 시작 버튼은 게임 진입과 오디오 언락을 동시에 수행한다.

---

## 1.2 Tutorial Screen / 조작 안내 화면

### 1. 화면 목적

플레이어가 조작법을 익히는 화면.
Spacebar를 누르면 속도가 빨라지고, 손을 떼면 속도가 천천히 줄어드는 감각을 플레이어가 직접 느끼도록 한다.
이 화면은 정답 속도를 찾는 단계가 아니라, 속도가 어떻게 변화하는지 몸으로 익히는 구간이다.

### 2. 화면 구성 요소

- 조작법 안내 문구
- 플레이어 조작에 따라 움직이는 캐릭터
- 플레이어 조작에 따라 흐름이 변하는 배경
- 중앙 게임 영역
- 양옆 배너 영역
- BGM / 효과음

### 3. 플레이어 행동

- 빠르게 움직이는 조작법 문구가 나오면 Spacebar를 눌러 속도를 올린다.
- 천천히 움직이는 조작법 문구가 나오면 Spacebar에서 손을 떼 속도를 줄인다.
- 조작법 완료 문구가 노출될 때까지 안내에 따라 조작한다.

### 4. 사용 문구

빠른 조작법 문구:
조금 빨라져볼까요?
Spacebar 키를 눌러보세요.

느린 조작법 문구:
이번엔 천천히 가볼까요?
Spacebar에서 손을 떼보세요.

조작법 완료 문구:
좋아요.
속도는 언제든 바뀔 수 있어요.

### 5. 비주얼 / 연출

- 배경 플레이 화면이 천천히 움직인다.
- 캐릭터 또는 길이 은근하게 주행 중인 듯 보인다.
- 빠른 조작법 문구가 화면에 노출된다.
- 플레이어가 Spacebar를 누르면 캐릭터와 배경 흐름이 점점 빨라진다.
- 빠르게 움직이는 상태를 약 5초간 경험하게 한다.
- 이후 느린 조작법 문구가 화면에 노출된다.
- 플레이어가 Spacebar에서 손을 떼면 캐릭터와 배경 흐름이 점점 느려진다.
- 느리게 움직이는 상태를 약 5초간 경험하게 한다.
- 이후 조작법 완료 문구가 화면에 노출된다.
- 배너는 아직 과하게 시끄럽지 않다.

### 6. 사운드

- BGM과 효과음이 재생된다.
- Spacebar를 누르면 발소리나 배경 리듬이 조금 빨라진다.
- Spacebar에서 손을 떼면 발소리나 배경 리듬이 천천히 가라앉는다.
- 조작 완료 시 과한 성공 효과음이 아니라 부드러운 확인 효과음을 사용한다.

### 7. 진입 조건

- Title Screen에서 시작 버튼을 눌렀을 때 진입한다.

### 8. 전환 조건

- 빠르게 움직이기 단계와 천천히 움직이기 단계를 완료하고, 조작법 완료 문구가 화면에 노출되면 Find Pace Screen / 내 속도 찾기 화면으로 전환된다.

### 9. 주의사항

- 이 화면에서는 특정 속도를 정답처럼 유도하지 않는다.
- 이 화면의 목적은 조작 판정이 아니라 조작 감각 학습이다.

## 1.3 Find Pace Screen / 내 속도 찾기 화면

### 1. 화면 목적

플레이어가 자신의 속도를 찾는 화면.
이 화면은 게임이 정해준 속도를 맞추는 단계가 아니라, 플레이어가 오래 머물 수 있는 편안한 속도를 스스로 찾아가는 단계다.
플레이어는 Spacebar를 누르고 떼며 속도를 조절하고, 특정 속도에 안정적으로 머물면 “머무는 중…” 게이지가 차오르는 경험을 한다.

### 2. 화면 구성 요소

- 내 속도 찾기 안내 문구
- 플레이어 캐릭터
- 배경 주행 연출
- 중앙 게임 영역
- 양옆 배너 영역
- 현재 속도에 반응하는 배경 흐름
- “머무는 중…” 안착 게이지
- 속도 변화에 반응하는 BGM / 효과음

### 3. 플레이어 행동

- Spacebar를 누르면 속도가 서서히 증가한다.
- Spacebar에서 손을 떼면 속도가 서서히 감소한다.
- 플레이어는 자신이 편안하다고 느끼는 속도 근처에 머무르려고 시도한다.
- 한 속도에 안정적으로 머물면 “머무는 중…” 게이지가 차오른다.
- 너무 빠르거나 너무 느려지면 게이지 차오름이 멈추거나 느려진다.

### 4. 사용 문구

메인 문구:
이제 가장 편안한 속도로 걸어보세요.
오래 머물 수 있는 리듬이면 충분해요.

게이지 문구:
머무는 중…

### 5. 비주얼 / 연출

- 플레이어 캐릭터는 계속 앞으로 이동한다.
- Spacebar를 누르면 배경 흐름이 점점 빨라진다.
- Spacebar에서 손을 떼면 배경 흐름이 점점 느려진다.
- 특정 속도에 안정적으로 머무르면 화면이 조금 더 선명하고 차분해진다.
- “정답 속도”처럼 보이는 강한 빛이나 명확한 유도 연출은 사용하지 않는다.
- 안착 게이지는 점수처럼 보이지 않게 부드럽게 차오른다.
- 양옆 배너는 아직 강하게 시끄럽지 않고, 낮은 수준의 외부 소음처럼 존재한다.

### 6. 사운드

- BGM은 계속 재생된다.
- 속도가 너무 빠르거나 느릴 때는 음악의 리듬이 살짝 어긋난 느낌을 준다.
- 안정적으로 머물 때는 발소리, 호흡, 음악 그루브가 조금 더 고르게 맞물린다.
- 강한 성공 효과음은 사용하지 않는다.

### 7. 진입 조건

- Tutorial Screen / 조작 안내 화면을 완료했을 때 진입한다.

### 8. 전환 조건

- 플레이어가 일정 시간 동안 한 속도에 안정적으로 머물러 “머무는 중…” 게이지를 가득 채우면 Main Play Screen / 본 게임 화면으로 전환된다.

### 9. 주의사항

- 평균 속도를 통보하는 방식으로 보이면 안 된다.
- 특정 속도가 정답처럼 느껴지면 안 된다.
- 플레이어가 직접 찾아서 안착했다는 체감이 중요하다.
- 실패, 오답, 다시 시작 같은 표현은 사용하지 않는다.

## 1.4 Main Play Screen / 본 게임 화면

### 1. 화면 목적

플레이어가 확정한 자신의 속도로 본격적으로 달리기 시작하는 화면.
바깥의 속도가 등장하기 전, 잠시 평온한 구간을 제공해 플레이어가 자신의 속도를 다시 몸에 익히도록 한다.

### 2. 화면 구성 요소

- 플레이어 캐릭터
- 배경 주행 연출
- 중앙 게임 영역
- 양옆 배너 영역
- 내 속도 유지 상태를 반영하는 배경 / 사운드
- 안정 게이지 영역
- 본 게임 진입 안내 문구

### 3. 플레이어 행동

- Spacebar를 누르고 떼며 속도를 조절한다.
- 방금 확정한 내 속도 구간으로 돌아가거나 유지하려고 시도한다.
- 외부 압박이 등장하기 전, 자신의 리듬을 다시 익힌다.

### 4. 사용 문구

진입 문구:
내 속도대로..

### 5. 비주얼 / 연출

- 본 게임 시작 직후에는 비교적 평온한 배경으로 시작한다.
- 양옆 배너는 조금씩 존재감을 키우지만, 아직 강하게 흔들지는 않는다.
- 안정 게이지는 화면에 표시되지만, 즉시 압박감을 주지 않는다.
- 플레이어가 내 속도 구간에 가까울수록 배경이 또렷하고 부드럽게 흐른다.
- 구간에서 멀어질수록 배경 흐름이 살짝 흔들리거나 번진다.

### 6. 사운드

- BGM은 본 게임 레이어로 자연스럽게 전환된다.
- 내 속도에 가까우면 발소리와 음악 리듬이 맞물린다.
- 구간에서 멀어지면 리듬이 살짝 어긋난다.

### 7. 진입 조건

- PFind Pace Screen / 내 속도 찾기 화면에 내 속도 게이지가 다 찼을 때 진입한다.

### 8. 전환 조건

- 본 게임 시작 후 일정 시간이 지나면 Other Pace Encounter / 다른 존재 등장 화면 상태로 전환된다.
- 이때 화면 자체가 완전히 바뀐다기보다, 본 게임 화면 위에 다른 존재 등장 이벤트가 시작되는 방식으로 처리할 수 있다.

### 9. 주의사항

- 본 게임에 들어왔다고 해서 긴장감을 갑자기 높이지 않는다.
- 실패 조건은 만들지 않는다.

---

## 1.6 Other Pace Encounter / 다른 존재 등장 화면

### 1. 화면 목적

외부의 속도를 상징하는 다른 존재가 등장하는 화면.
이 존재는 경쟁자나 적이 아니라, 플레이어가 의식할 때 자기 속도를 흔들 수 있는 바깥의 리듬이다.

### 2. 화면 구성 요소

- 플레이어 캐릭터
- 뒤에서 다가오거나 옆을 스쳐 지나가는 다른 존재
- 중앙 게임 영역
- 양옆 배너 영역
- 안정 게이지
- 배경 흔들림 / 흐림 효과
- 등장 안내 문구

### 3. 플레이어 행동

- 다른 존재를 따라가려 하지 않고 자신의 속도를 유지한다.
- Spacebar를 누르고 떼며 내 속도 구간으로 돌아오려고 한다.
- 다른 존재가 지나가는 동안 안정 게이지를 채운다.

### 4. 사용 문구

등장 문구:
바깥의 속도가 스쳐 갑니다.

### 5. 비주얼 / 연출

- 다른 존재가 뒤에서 다가와 플레이어를 아주 조금 앞서간다.
- 다른 존재는 플레이어를 쳐다보거나 공격하지 않는다.
- 다른 존재에게 순위, 이름, 체력바, 속도 표시를 붙이지 않는다.
- 플레이어가 다른 존재의 속도에 끌려가듯 빨라지면 화면이 조금 흔들린다.
- 내 속도로 돌아오면 흔들림이 줄어든다.

### 6. 사운드

- 다른 존재가 가까워질수록 주변 소음이나 배너 소리가 살짝 커진다.
- 단, 위협적인 적 등장 효과음처럼 만들지 않는다.
- 내 속도에 가까워지면 소음이 조금씩 멀어진다.

### 7. 진입 조건

- Main Play Screen 진입 후 일정 시간이 지났을 때 발생한다.
- 1회차, 2회차, 3회차 안정 이벤트 전마다 반복해서 등장한다.

### 8. 전환 조건

- 다른 존재가 등장한 상태에서 플레이어가 내 속도 구간에 머물러 안정 게이지를 가득 채우면 Stability Progress Screen 완료 상태로 전환된다.
- 안정 게이지가 가득 차면 다른 존재는 자연스럽게 사라진다.

### 9. 주의사항

- 다른 존재를 적처럼 만들지 않는다.
- 따라잡는 보상을 만들지 않는다.
- 다른 존재보다 빠르게 가는 것을 목표처럼 보이게 하면 안 된다.
- 플레이어가 흔들려도 실패하지 않는다.

## 3.7 Stability Progress Screen / 안정 게이지 진행 화면

### 1. 화면 목적

플레이어가 내 속도 구간 안에 머무르고 있음을 시각적으로 알려주는 화면 또는 상태.
이 화면은 별도의 독립 화면이라기보다, 본 게임 중 계속 표시되는 진행 상태에 가깝다.

### 2. 화면 구성 요소

- 안정 게이지
- 플레이어 캐릭터
- 현재 배경 안정 상태
- 양옆 배너 상태
- 다른 존재 등장 여부
- 상태 피드백 문구

### 3. 플레이어 행동

- Spacebar를 조절해 내 속도 구간에 머무른다.
- 게이지를 채우기 위해 속도를 정확히 맞추는 것이 아니라, 자신의 속도 근처에 안정적으로 머무른다.
- 구간을 벗어나면 다시 천천히 돌아온다.

### 4. 사용 문구

안정 구간 안:

좋아요.
리듬이 돌아오고 있어요.

게이지 진행 중:

리듬이 이어지는 중…

구간 이탈:

조금 멀어졌어요.
괜찮아요. 다시 찾으면 됩니다.

게이지 멈춤:

잠시 멈췄어요.
다시 돌아오면 이어집니다.

### 5. 비주얼 / 연출

- 안정 게이지는 줄어들어 죽는 시계처럼 보이면 안 된다.
- 내 속도 구간에 머무를 때 게이지가 부드럽게 차오른다.
- 구간 밖으로 벗어나면 게이지 차오름이 멈추거나 아주 살짝 되돌아간다.
- 게이지가 멈춰도 경고색이나 실패 연출을 사용하지 않는다.
- 게이지가 가득 차면 점수 획득이 아니라 “한 번 찾음”으로 표현한다.
- 안정 상태에서는 배경이 선명해지고, 색감이 따뜻하게 가라앉는다.
- 불안정 상태에서는 배경이 번지거나 흐려지고, 배너가 조금 더 시끄러워진다.

### 6. 사운드

- 안정 구간 안에서는 발소리와 BGM이 고르게 맞물린다.
- 구간 밖에서는 호흡이 가빠지거나 늘어지는 느낌을 줄 수 있다.
- 게이지가 가득 찰 때는 조용한 확인 효과음을 사용한다.

### 7. 진입 조건

- Main Play Screen 진입 후 항상 활성화된다.
- 다른 존재가 등장한 상태에서는 안정 게이지 충전이 핵심 진행 조건이 된다.

### 8. 전환 조건

- 안정 게이지가 가득 차면 현재 회차에 따라 Return Screen으로 이동한다.
    - 1회 충전 완료 → First Return Screen
    - 2회 충전 완료 → Second Return Screen
    - 3회 충전 완료 → Third Return Screen

### 9. 주의사항

- 게이지를 제한 시간처럼 보이게 만들지 않는다.
- “성공”, “실패”, “미션 완료” 같은 표현은 사용하지 않는다.
- 게이지는 플레이어를 압박하는 장치가 아니라, 자기 속도에 머무르고 있음을 확인해주는 장치다.

## 3.8 Return Screens / 1·2·3번째 찾음 화면

### 1. 화면 목적

플레이어가 외부의 속도에 흔들린 뒤 다시 자기 속도를 찾았음을 인정하는 화면.
세 번의 Return Screen은 단순 반복이 아니라 감정 성장 곡선이다.

1번째 찾음은 혼란, 2번째 찾음은 인식, 3번째 찾음은 체화를 표현한다.

### 2. 화면 구성 요소

- 회차별 인정 문구
- 차분해진 배경
- 사라지는 다른 존재
- 안정된 플레이어 캐릭터
- 양옆 배너의 소음 감소
- 다음 구간으로 자연스럽게 이어지는 주행 연출

### 3. 플레이어 행동

- 별도의 조작 없이 문구와 연출을 확인한다.
- 일정 시간이 지나면 다음 평온 구간 또는 다음 만남으로 자동 전환된다.
- 3번째 찾음 후에는 Clear Screen으로 이동한다.

### 4. 사용 문구

1번째 찾음 — 혼란:

처음으로 돌아왔어요.
아직 낯설어도 괜찮아요.

2번째 찾음 — 인식:

이제 조금 알 것 같아요.
당신의 리듬은 사라지지 않았어요.

3번째 찾음 — 체화:

이제 다시 찾을 수 있어요.
당신의 속도는 당신 안에 있어요.

### 5. 비주얼 / 연출

- 안정 게이지가 가득 차면 다른 존재가 서서히 흐려지며 사라진다.
- 배경 흔들림이 줄어들고, 화면이 다시 선명해진다.
- 양옆 배너는 잠시 조용해진다.
- 회차별로 연출 강도를 조금씩 다르게 한다.
    - 1회차: 낯설지만 처음으로 안정되는 느낌
    - 2회차: 흔들림의 의미를 알아차리는 느낌
    - 3회차: 자기 속도가 몸에 남은 듯한 느낌

- 과한 클리어 연출이나 점수 표시를 사용하지 않는다.

### 6. 사운드

- 다른 존재가 사라질 때 주변 소음이 줄어든다.
- 안정된 발소리와 호흡이 다시 들린다.
- 회차가 올라갈수록 BGM의 안정 레이어가 조금 더 분명해질 수 있다.

### 7. 진입 조건

- Stability Progress Screen에서 안정 게이지가 가득 찼을 때 진입한다.

### 8. 전환 조건

- 1번째 찾음 화면 이후 일정 시간이 지나면 다시 Main Play Screen의 평온 구간으로 이동한다.
- 2번째 찾음 화면 이후 일정 시간이 지나면 다시 Main Play Screen의 평온 구간으로 이동한다.
- 3번째 찾음 화면 이후 일정 시간이 지나면 Clear Screen / 속도 찾음 화면으로 이동한다.

### 9. 주의사항

- “1단계 성공”, “2단계 성공”처럼 단계 클리어 느낌을 주지 않는다.
- 회차는 점수가 아니라 감정 변화로 구분한다.
- 플레이어가 이긴 것이 아니라 자기 속도로 돌아왔다는 느낌을 줘야 한다.

---

## 1.9 Clear Screen / 속도 찾음 화면

### 1. 화면 목적

플레이어가 세 번의 흔들림을 지나 자신의 속도를 찾았음을 인정하는 화면.
이 화면은 승리 화면이 아니라 인정의 순간이다.

### 2. 화면 구성 요소

- 클리어 메인 문구
- 서브 안내 문구
- 안정된 배경
- 플레이어 캐릭터
- 양옆 배너 전환 연출
- 계속 / 종료 선택으로 이어지는 UI

### 3. 플레이어 행동

- 화면의 문구를 확인한다.
- 이후 Continue or End Screen에서 계속 달릴지, 여기서 멈출지 선택한다.

### 4. 사용 문구

메인 문구:

당신의 속도를 찾았습니다.

서브 문구:

이곳에는 피니시가 없습니다.
계속 달려도 되고, 여기서 멈춰도 괜찮아요.

### 5. 비주얼 / 연출

- 화면은 감정적 정점으로 처리한다.
- 점수판, 랭킹, 기록표는 표시하지 않는다.
- 배경은 가장 안정된 상태로 표현한다.
- 양옆 배너가 일반 광고에서 지원 회사 배너로 전환된다.
- 회사 배너는 과한 광고가 아니라 애정 어린 오마주처럼 보여야 한다.
- 캐릭터는 멈추지 않고 계속 나아가도 되고, 잠시 안정된 자세로 표현해도 된다.

### 6. 사운드

- BGM은 가장 안정적인 형태로 정리된다.
- 클리어 효과음은 조용하고 따뜻한 인정의 느낌이어야 한다.
- 승리 팡파르나 과한 보상음은 사용하지 않는다.

### 7. 진입 조건

- 3번째 안정 게이지 충전 완료 후 Third Return Screen을 지나 진입한다.

### 8. 전환 조건

- 일정 시간 후 Continue or End Screen / 계속 또는 종료 선택 화면으로 이동한다.
- 또는 같은 화면 안에서 선택 버튼이 나타날 수 있다.

### 9. 주의사항

- “Clear”, “Victory”, “Win” 같은 표현은 사용하지 않는다.
- 이 화면의 핵심은 승리가 아니라 “인정”이다.
- 플레이어가 끝내기를 선택해도 패배처럼 느껴지지 않도록 해야 한다.

---

## 1.10 Continue or End Screen / 계속 또는 종료 선택 화면

### 1. 화면 목적

플레이어가 자신의 속도를 찾은 뒤, 계속 달릴지 여기서 멈출지 선택하는 화면.
이 화면은 선택의 우열이 없어야 한다. 계속하는 것도 정답이 아니고, 멈추는 것도 포기가 아니다.

### 2. 화면 구성 요소

- 선택 안내 문구
- 계속 달리기 버튼
- 오늘은 여기까지 버튼
- 안정된 배경
- 플레이어 캐릭터
- 차분해진 양옆 배너

### 3. 플레이어 행동

- “계속 달리기”를 선택하면 게임은 계속 주행 상태로 이어진다.
- “오늘은 여기까지”를 선택하면 Landscape Ending Screen으로 이동한다.

### 4. 사용 문구

안내 문구:

계속 달려도 되고,
여기서 멈춰도 괜찮아요.

버튼:

계속 달리기
오늘은 여기까지

보조 문구 후보:

어느 쪽도 늦지 않습니다.
지금의 선택도 당신의 속도입니다.

### 5. 비주얼 / 연출

- 두 버튼은 같은 무게로 배치한다.
- “계속 달리기”를 더 강한 CTA처럼 보이게 하지 않는다.
- “오늘은 여기까지”를 종료나 포기처럼 보이게 하지 않는다.
- 배경은 안정된 주행 상태를 유지한다.
- 양옆 배너는 조용하거나, 지원 회사 배너 상태를 유지한다.

### 6. 사운드

- BGM은 안정된 상태로 유지된다.
- 버튼 선택 시 부드러운 선택 효과음을 사용한다.

### 7. 진입 조건

- Clear Screen 이후 진입한다.

### 8. 전환 조건

- “계속 달리기” 선택 시 Main Play Screen의 자유 주행 상태로 이어진다.
- “오늘은 여기까지” 선택 시 Landscape Ending Screen / 당신의 풍경 엔딩 화면으로 이동한다.

### 9. 주의사항

- 종료 선택을 부정적으로 표현하지 않는다.
- “나가기”, “포기”, “종료” 같은 차가운 표현보다 “오늘은 여기까지”처럼 선택의 느낌을 주는 문구를 사용한다.
- 이 화면에서도 피니시가 없다는 게임 철학을 유지한다.

---

## 1.11 Landscape Ending Screen / 당신의 풍경 엔딩 화면

### 1. 화면 목적

플레이어가 지나온 게임 화면을 하나의 풍경으로 남기는 엔딩 화면.
이 화면은 점수나 결과를 보여주는 화면이 아니라, 플레이어가 자신의 속도로 지나온 시간을 선물처럼 받는 화면이다.

### 2. 화면 구성 요소

- 엔딩 메인 문구
- 엔딩 서브 문구
- 캡처된 게임 풍경 이미지
- 내 풍경 저장하기 버튼
- 다시 걸어보기 버튼
- 중앙 게임 영역
- 필요 시 양옆 배너는 숨기거나 차분한 상태로 유지

### 3. 플레이어 행동

- 자신의 풍경 이미지를 확인한다.
- “내 풍경 저장하기” 버튼을 눌러 이미지를 저장한다.
- “다시 걸어보기” 버튼을 눌러 처음부터 다시 시작할 수 있다.

### 4. 사용 문구

메인 문구:

당신의 풍경이 도착했어요.

서브 문구:

빠르거나 느린 기록이 아니라,
당신이 지나온 리듬입니다.

버튼:

내 풍경 저장하기
다시 걸어보기

### 5. 비주얼 / 연출

- 게임 화면을 캡처한 이미지가 중앙에 표시된다.
- 이 이미지는 점수 결과표처럼 보이면 안 된다.
- 풍경 이미지는 플레이어가 지나온 경험의 흔적으로 표현한다.
- 가능하다면 픽셀아트 엽서나 작은 기념 이미지처럼 보여준다.
- 배경은 조용하고 정리된 느낌을 유지한다.
- 양옆 배너는 사라지거나, 매우 차분한 상태로 남긴다.

### 6. 사운드

- BGM은 엔딩용으로 가장 잔잔한 상태를 유지한다.
- 저장 버튼 클릭 시 가벼운 저장 효과음을 사용할 수 있다.
- 엔딩에서 과한 축하음은 사용하지 않는다.

### 7. 진입 조건

- Continue or End Screen에서 “오늘은 여기까지”를 선택했을 때 진입한다.

### 8. 전환 조건

- “내 풍경 저장하기” 클릭 시 현재 풍경 이미지를 저장한다.
- “다시 걸어보기” 클릭 시 Title Screen 또는 Tutorial 이후 단계로 이동한다.
- MVP에서는 처음부터 다시 시작하는 흐름을 기본으로 한다.

### 9. 주의사항

- 공유 대상은 점수가 아니라 풍경이어야 한다.
- 순위, 기록, 속도 수치, 성공률을 노출하지 않는다.
- 풍경 저장은 보상이 아니라 선물처럼 느껴져야 한다.
- 소셜 공유 링크는 MVP 범위에서 제외하고, 이미지 저장만 우선 구현한다.
