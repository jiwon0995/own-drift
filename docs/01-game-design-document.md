# 게임 기획서 (GDD) — 나의 속도

> 브레인스토밍 정리본. 확정된 내용은 채워져 있고, 더 정해야 할 부분은 **□ 미정**으로 표시.

**관련 문서**
- 화면별 상세 명세(구성요소·문구·연출·진입/전환 조건) → `03-screens.md`
- 스토리 비블 → 별도 문서로 관리 예정 (`02-story-bible.md`)

## 1. 컨셉 · 의도

**한 줄 피치**
빠르게 도착하는 게임이 아니라, 자기만의 속도를 찾고 그 리듬을 지켜내는 감성 웹 게임.

**왜 이 게임인가**
과제의 '속도'를 '시간'과 함께 떠올렸고, 둘 다 절대적이지 않은 **상대적 개념**이라고 봤다. 살다 보면 남들 속도에 맞춰야 할 것 같고 나만 뒤처진 것 같은 압박을 느끼지만, 속도도 시간도 상대적이기에 중요한 건 '내 속도'를 찾아 가는 것이다. 또한 인생을 완성해야 할 퀘스트의 연속처럼 여기기 쉽지만, 사실 '완성되는 인생'은 없다. 이 생각을 게임으로 옮긴 것이 '내 속도를 찾는 게임'이다.

**타깃 감정**
차분함, 자기 발견, 압박 속에서 내 리듬을 지켜낼 때의 안도.

**핵심 결정: 이 게임엔 실패가 없다.**
자기 속도를 찾는 데 실패란 없다. 늦더라도, 헤매더라도 계속 가면 된다 — 될 때까지. 게임은 플레이어를 처벌하지 않고, 세 번 찾아낼 때까지 인내심 있게 기다린다.

---

## 2. 디자인 기둥 (Design Pillars)

1. **내 속도를 발견하고 되찾는 경험**
2. **외부의 압박 속에서 내 리듬을 지키는 것**
3. **경쟁도 처벌도 없는 차분함**
   **이 게임이 아닌 것 (Non-goals)**
- 레이싱 / 속도 경쟁 게임이 아니다
- 반응속도 테스트가 아니다
- '도착(finish)'을 목표로 하는 게임이 아니다
- 실패·처벌이 없다
---

## 3. 코어 루프

캐릭터가 앞으로 나아간다 → 속도를 조절한다 → **배경·BGM·양옆 배너가 속도에 반응**한다 → 그 감각을 단서로 내 리듬을 더듬어 찾는다 → 내 속도에 안착한다 → 외부의 압박을 견디며 그 리듬을 지킨다 → 인정받는다("당신의 속도를 찾았다").

핵심: **텍스트로 설명하지 않고, 감각(시각·청각)으로 자기 속도를 깨닫게 한다.**

---

## 4. 전체 구조

'내 속도 찾기'를 한 번이 아니라 **세 번 성공**해야 클리어된다. 다른 존재는 **세 번 성공할 때까지 반복해서 등장**한다 — 플레이어가 헤매면 계속 다시 찾아오고, 성공할 때마다 하나씩 채워진다.

```
혼자 달림 (캘리브레이션 · 측정 1회)
   → 평온
   → 다른 존재 등장 → 견뎌내고 안정 게이지를 채우면 = 1번째 찾음   [혼란]
   → 평온
   → 다른 존재 다시 등장 → 2번째 찾음                              [인식]
   → 평온
   → 다른 존재 다시 등장 → 3번째 찾음                              [체화]
   → "당신의 속도를 찾았다" → 계속할지 / 끝낼지 선택
```

- 세 번의 *성공*은 **반복이 아니라 성장 곡선**(혼란 → 인식 → 체화)으로 설계한다.
- 성공하지 못한 시도는 실패가 아니라 그냥 **다시 시도**다. 다른 존재가 다시 올 뿐 잃는 것은 없다.
- 시도와 시도 사이의 **평온한 구간**이 이 게임의 알맹이.

## 5. 게임 진행 플로우 (화면별 요약)

> 화면별 상세 명세(구성요소·문구·연출·진입/전환 조건)는 `03-screens.md` 참고. 여기서는 흐름의 큰 그림만.

1. **Title** — 시작 화면. 메인: "달려도, 걸어도 괜찮아요. 당신만의 속도를 찾아볼게요." 버튼 `내 속도 찾아보기`. 시작이 **오디오 언락**도 겸함.
2. **Tutorial** — 조작 안내. **Spacebar 홀드(가속) / 릴리스(감속)** 감각 학습. 정답 속도를 유도하지 않는 *중립 구간*.
3. **Find Pace** — 내 속도 찾기. "이제 가장 편안한 속도로 걸어보세요." 한 속도에 안정되게 머물면 **"머무는 중…" 게이지**가 차오름 → 가득 차면 본 게임으로.
4. **Main Play** — 본 게임 진입. "내 속도대로.." 평온한 구간으로 시작, 일정 시간 후 다른 존재 등장.
5. **Other Pace Encounter** — 외부의 속도가 등장. "바깥의 속도가 스쳐 갑니다." 뒤에서 다가와 스쳐 지나가는 흐릿한 존재. *경쟁자/적이 아니라 의식하면 흔들리는 바깥의 리듬.*
6. **Stability Progress** — 본 게임 중 항상 활성화된 상태. 내 구간에 머물수록 안정 게이지가 차오르고, 가득 차면 다른 존재가 사라짐. ("좋아요. 리듬이 돌아오고 있어요." / "조금 멀어졌어요. 괜찮아요. 다시 찾으면 됩니다.")
7. **Return 1 — 혼란** — "처음으로 돌아왔어요. 아직 낯설어도 괜찮아요."
8. **Return 2 — 인식** — "이제 조금 알 것 같아요. 당신의 리듬은 사라지지 않았어요."
9. **Return 3 — 체화** — "이제 다시 찾을 수 있어요. 당신의 속도는 당신 안에 있어요."
10. **Clear** — "당신의 속도를 찾았습니다." 양옆 배너가 일반 광고 → 지원 회사 배너로 전환(이스터에그). "이곳에는 피니시가 없습니다."
11. **Continue or End** — 두 버튼 같은 무게로: `계속 달리기` / `오늘은 여기까지`. 종료가 포기처럼 보이지 않게.
12. **Landscape Ending** — "당신의 풍경이 도착했어요." 캡처된 게임 화면을 풍경 이미지로 표시. `내 풍경 저장하기` / `다시 걸어보기`(Title로 복귀).
    **카피 톤 원칙**: 판단이 아니라 *인정*. 재촉하지 않음. "도전/기록/빨리"류 표현 금지.

## 6. 게임 규칙 명세

### 캐릭터 이동 · 조작 (확정)
- 캐릭터는 **자동으로 앞으로 나아간다.**
- 조작: **Spacebar 홀드 = 가속 / 릴리스 = 감속.** 단일 키 홀드 방식.
- **관성 있음** — 즉각 멈추거나 튀지 않고 부드럽게 따라온다. (감성의 핵심이자 '손맛'의 원천)
- 단일 키 선택 이유: 두 키 조합보다 직관적이고, 모바일 탭/홀드로도 자연 이식 가능.
### 속도 기록 · 내 속도 찾기 (피드백 반영 — 개선)
- **평균이 아니라 '안착'으로.** 처음 달린 속도의 평균을 통보하는 게 아니라, 플레이어가 *직접 편안한 속도를 찾아 확정*한다.
- 흐름: 중립 자유 주행(Tutorial) → "편하게 유지할 수 있는 속도를 찾아보세요"(Find Pace) → 한 속도에 안정되게 머물면 **'머무는 중…' 게이지** 차오름 → 가득 차면 그 속도가 '내 속도'로 확정, 본 게임 시작.
- **신호 원칙 (수렴 방지)**: 특정 속도를 '정답'으로 빛내는 *유도 신호*는 쓰지 않는다. *어떤 속도든 꾸준히 유지하면 잔잔해지는* **확인 신호**만 준다. 양 극단(아주 빠름/느림)에서만 살짝 불편하고, 넓은 가운데가 다 열려 있어 사람마다 다른 데 안착한다.
- 내 속도 구간 = 확정된 속도 ± 허용폭.
- 참고: 비교·리더보드가 없으므로 속도가 남과 비슷해도 무방. 핵심은 *내가 찾아 확정한 속도*라는 체감.
### 안정 게이지
- **줄어들어 죽는 시계가 아니라, 내 구간에 머물수록 차오르는 진행 게이지.**
- 다른 존재가 끌어당기는 동안 내 구간 안에 머물면 게이지가 찬다. **가득 차면 = "한 번 찾음"** → 다른 존재가 사라진다.
- 구간을 벗어나면 차오름이 멈추거나 살짝 되돌아갈 뿐, **절대 실패로 이어지지 않는다.** 경고색·실패 연출 사용 금지.
### 안정 구간 판정
- 현재 속도가 내 구간 안인지 매 프레임 확인. **흔들림 방지**: 히스테리시스/누적치 적용.
### 다른 존재 (외부의 압박)
- 본 게임 시작 후 **세 번 성공할 때까지** 매번 뒤에서 다가와 스쳐 지나가는 존재가 등장.
- **경쟁자로 읽히지 않게**: 순위·이름·체력바·속도 표시·결승선 없음 / 나를 쳐다보거나 반응하지 않음 / 흐릿하게 스쳐 사라짐.
- **따라가면 손해, 따라잡아도 보상 없음.** 쫓으면 구간 이탈 → 흔들림·게이지 멈춤. 쫓아도 그냥 사라질 뿐.
- **소멸 조건**: 끌어당김을 견디며 안정 게이지를 채우면 사라짐.
- 의미: **남들은 내가 그들을 의식하는 동안만 힘을 가진다.**
- □ 미정: 다른 존재의 구체적 비주얼/형태(픽셀 시안).
### 클리어 (실패 없음)
- **이 게임엔 실패가 없다.**
- **클리어 = 도착이 아니라 인정.** 세 번 채우면 "당신의 속도를 찾았다"로 인정.
- 클리어 후 **계속 플레이하거나 게임을 나가도 된다** — 떠나는 것은 패배가 아니다.
- 클리어 순간 양옆 배너가 일반 광고 → 지원 회사 배너로 바뀐다 (9. 비주얼·레이아웃 참고).

## 7. 난이도 / 긴장 설계 원칙

- 실패가 없으므로 **난이도를 단계적으로 올릴 필요는 없다.** 성장은 게임이 어려워져서가 아니라 플레이어가 이해해서 일어난다.
- 긴장은 위협이 아니라 **몰입·발견·손맛**에서 온다. 관성·미세 조정이 손맛을 책임진다.
- **구간을 좁히거나 조작을 까다롭게 만들지 않는다.**

## 8. 피드백 언어

**원리: 양극단은 불편하게(보편) / 안정될수록 편안하게(개인).**
"정답 속도"를 가리키는 *유도 신호*는 쓰지 않고, "잘 머물고 있음"을 비추는 *확인 신호*를 준다.

- **구간 안 · 안정**: 배경이 또렷하고 부드럽게 흐름, 색이 따뜻하게 가라앉음, 발소리·호흡이 고른 리듬, 음악 그루브가 맞물림, 배너 차분, 안정 게이지 차오름.
- **구간 밖 · 불안정**: 배경이 번지고 흔들리거나 끌림, 색이 빠짐, 호흡이 가빠지거나 늘어짐, 음악이 어긋남, 배너가 시끄러워짐, 게이지 멈춤.
- **추천 조합 (솔로 일정 현실안)**: 배경 선명도 + 발소리·호흡(또는 음악 그루브) + 유지의 손맛 + 안착 게이지. 여러 채널이 *같은 리듬으로 맞물리는 '찰칵'*이 가장 강한 '적절함' 신호.
- 캐릭터 자세(애씀 vs 편안)는 효과가 크지만 도트 애니 비용이 있어 **여유 시.**
- **클리어 순간**: 감정적 정점 — 점수 화면이 아니라 *인정*의 순간. 연출에 가장 공을 들인다. 승리 팡파르·과한 보상음 금지, 조용하고 따뜻한 확인 효과음.

## 9. 비주얼 · 레이아웃 디렉션

**아트 스타일: 2000년대 초반 PC게임 + 도트(픽셀아트)**
- 저해상도 픽셀아트로 통일 (스코프 절약 + 의도적 레트로 무드).
- 픽셀/비트맵 폰트 (영문 Press Start 2P, 한글 둥근모꼴 등), `image-rendering: pixelated`로 또렷한 확대.
- 제한된 저채도 팔레트로 통일감. CRT 스캔라인은 *살짝만*.
  **레이아웃: 중앙 게임 + 양옆 배너 (옛 웹게임 포털 느낌)**
- 3단 구성 — 가운데 게임 창, 양옆에 세로 배너.
- **배너 = 외부 압박의 구현.** 시끄럽게 재촉하는 세상이 차분한 중심(게임)을 둘러싼다.
- □ 미정(스트레치): 배너를 피드백에 묶기 — 휩쓸리면 더 번쩍이고, 안착하면 조용해짐.
  **배너 콘텐츠 & 이스터에그 (확정)**
- 플레이 중 양옆 배너는 옛 웹게임 포털풍 **일반 광고**(시끄러운 외부 압박).
- **내 속도를 찾으면(클리어) 그 자리에 지원 회사의 배너가 나타난다.** 위트이자 윙크.
- 톤 주의: 광고가 아니라 *애정 어린 오마주*로.

## 10. 플랫폼 / 모바일 방침

- **데스크톱 키보드(Spacebar)가 1차**, 여기서 핵심 느낌을 완성.
- 모바일은 **"화면이 깨지지 않는 정도"**만. 3단 레이아웃이 좁아지면 양옆 배너를 숨기고 게임만 중앙에 — 자연스럽게 대응.
- 시간 남으면 **터치 홀드**(화면 어디든 길게 누르면 가속, 떼면 감속)를 추가. Spacebar와 동일 패턴이라 이식이 가볍다.
- **오디오 언락**: 시작 버튼(내 속도 찾아보기) 인터랙션으로 오디오를 켠다 (특히 iOS 필수).

## 11. 튜닝 파라미터 (전부 임시값, 밸런싱 대상)

| 파라미터 | 임시값 | 메모 |
|---|---|---|
| '머무는 중…' 안착 게이지 충전 시간 | □ | 내 속도 확정 단계 |
| 구간 허용폭 | ±15% | 너무 좁히지 말 것 |
| 가/감속 관성 계수 | □ | 손맛 |
| 안정 게이지 충전 속도 | □ | 가득 = 1회 성공 |

## 12. 스코프

**MVP에 포함**
- 자동 이동 + **Spacebar 홀드/릴리스** 가·감속(관성)
- 자유 주행(Tutorial · 중립) → '머무는 중…' 안착 → 내 속도 확정(Find Pace)
- 배경·BGM·배너의 속도/안정 반응 피드백
- 안정 구간 판정(히스테리시스), 안정 게이지(진행 표시)
- 다른 존재 반복 등장/소멸 (3회 성공까지)
- 회차별 Return Screen(혼란/인식/체화)
- Clear → Continue or End 선택
- 엔딩 '당신의 풍경' = **canvas 캡처 + 이미지 저장**, `다시 걸어보기`(Title 복귀)
- 픽셀아트 비주얼, 중앙 게임 + 양옆 배너, 클리어 시 회사 배너
- 데스크톱 우선, 모바일 비파손 대응
  **의도적으로 제외 / 스트레치 (+ 이유)**
- 실패·게임오버 — 테마상 의도적으로 없앰
- 리더보드·순위 — 경쟁 개념 배제
- **소셜 공유 링크** — 백엔드/이미지 호스팅 필요 → 일정상 MVP 제외. 이미지 저장만.
- 풍경이 주행에 따라 변형 — **스트레치**
- 배너 실시간 상태 반응 — **스트레치**
- 모바일 풀 최적화(터치 입력) — 시간 남으면

## 13. 완성 기준 (Definition of Done)

처음 보는 사람이 설명 없이 — **따라잡는 게 아니라 내 속도로 돌아가는 것**임을 감각으로 깨닫고, 세 번 내 속도를 찾아 "당신의 속도를 찾았다"에 도달할 수 있다. 그 과정에서 한 번도 "실패했다"는 좌절을 느끼지 않는다.
